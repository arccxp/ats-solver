A third idea is in the popup: Screenshot → “Smart” takes a picture only when the words are not enough (a figure, a picture answer, a question that is itself a picture, or one that names a passage that was not read), and goes without for an ordinary question. Shortcuts

Click a box, then press the keys you want: any key, with or without Ctrl, Alt or Shift. Esc cancels. A plain letter, digit or arrow key is ignored while you are typing in a text field; the rest work anywhere on the page. Press Save to keep them.

Developer

Shows Dump this page, Copy the last report and Save the log as a file in the popup. A report is kept whenever a run stops or the page script finds no question: the page as it was, what the run had done so far, and the last few hundred log lines — which service was picked, which model, what each one replied. Keys and tokens are stripped out of it before it is written, but it does contain the question text from the page, so read it before pasting it in public. Press Save to keep the switch.
